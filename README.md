## About

I’m an Android-first software engineer who builds complete products across mobile, desktop, web, backend, and AI. I’ve delivered **30+ end-to-end projects**, with particular focus on native Android APIs and polished, practical user experiences.

My work includes Android VPN networking, Bluetooth HID, Telecom and in-call experiences, media and storage tools, foreground services, on-device machine learning, real-time communication, desktop applications, and AI-powered automation.

I enjoy taking products from initial architecture through system integration, database and API design, interface development, packaging, and documentation.
